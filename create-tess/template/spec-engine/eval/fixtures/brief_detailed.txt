We need a small internal tool called Standup Log for our 12-person remote team. Every teammate posts a short daily update: what they did yesterday, what they're doing today, and any blockers. The app should be able to show a single team feed sorted by most recent post, with each entry showing the person's name, avatar, and timestamp. It should look clean and minimal, similar to a simple chat feed, using our existing brand colors (navy and a warm orange accent) and our logo in the top-left header. There should be a settings screen where an admin can add or remove teammates and set the daily reminder time.

Under the hood, the app should send a Slack reminder to each teammate at their configured local time if they haven't posted yet that day, using the Slack webhook integration we already use for other tools. When a teammate submits their update, the system should validate that all three fields are non-empty before saving it, and it should timestamp the entry in UTC. A background job should run every morning to reset the "posted today" flag for every teammate.

The data model needs a Teammate entity (name, email, avatar_url, timezone, slack_user_id) and an Update entity (teammate_id, yesterday_text, today_text, blockers_text, created_at). Each Update belongs to exactly one Teammate.

We are not going to build threaded replies or reactions in this version — that's explicitly out of scope for now. Success looks like: every teammate can post an update in under 30 seconds, the team feed loads in under a second, and the Slack reminder actually fires for anyone who hasn't posted by 10am their local time.
