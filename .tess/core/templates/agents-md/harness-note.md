This project's commands (`.tess/core/commands/**`) are rendered as Agent Skills at `.agents/skills/tess-<name>/SKILL.md` by the `codex` target — Codex, Gemini CLI, Cursor, Copilot CLI, OpenCode, Amp, Grok Build, Kimi Code, Qwen Code and DeepSeek Harness all read `.agents/skills/`. Run one by name in your own runtime's syntax: Codex `$tess-<name>` or `/skills` (explicit-only, never picked implicitly); Kimi Code `/skill:tess-<name>`; Grok Build and Qwen Code `/tess-<name>`. The `generic` target mirrors the same bodies as plain `prompts/<name>.md` for any other AGENTS.md-reading agent.

These are optional — read one only if invoked by name; this digest does not reproduce their contents (see the banner above for why it stays lean).
