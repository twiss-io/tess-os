# Cyra security verdict: PR #190 (v0.2.0 train: Codex skills + conformance)

Signed contract: the YAML front-matter above. The signature covers only the front-matter. This body is the human-readable record.

- Scope: the full diff, 194 paths. That includes the merged `ckpt/ct-1` (reviews/verdicts template exclusion) and `ckpt/eng-b-1` (render_outputs records and multi-entry status).
- Security verdict: **CLEAR** (disposition APPROVE). Findings: 0 critical, 0 high, 0 medium, 8 low.

## Threat model
The adversary is a prompt-injected or misaligned agent session, or a malicious contributor, with write access to the working tree. Its goals are to (a) get bytes into security-tier doctrine or the gate engine through a Tess write path, (b) disarm local guards without being noticed, or (c) reach the Codex runtime with instructions the operator never invoked.

## What changed, security-wise
- **Codex skills.** The codex target now renders `.agents/skills/tess-<cmd>/SKILL.md` plus `agents/openai.yaml` (`allow_implicit_invocation: false`). The new owned glob `.agents/skills/tess-*/**` takes precedence over the `.agents/**` never_touch for the `tess-` prefix only. User paths (`.agents/skills/my-skill/`, `.agents/skills/tess.md`) are still refused, which the tests assert. A pre-existing user file at a `tess-*` path is kept as foreign or hand-edited. `.codex/prompts/**` is retired: no longer owned or rendered, and never deleted.
- **Render outputs (eng-b-1).** Every render write now goes through `write_render_output`, which refuses a final-component symlink, keeps hand edits, respects protective statuses, and records `rendered_sha`. On 5c2d698, symlinks at CLAUDE.md, conductor/identity.md, .claude/settings.json, AGENTS.md or .codex/prompts/wake.md pointing at conductor/guardrails.md let render, restore and doctor --fix overwrite it. At this head all 12 command/path combinations I probed are refused.
- **Multi-entry status.** Capture quarantines the whole group when any entry in it is security tier. Publish, override and reset act on every entry. Doctor and update fail on mixed statuses.
- **Doctrine digest.** AGENTS.md gains worker scope fragments: dispatch rule, channel and file placement. The hard floor and gate-compliance sections are unchanged. Rule 1a is explicitly excluded for workers.
- **Unchanged against main:** gate, verdict and signing code, core/policy, the key registries, workflows and security-tier doctrine.

## Residual risk
- Hand edits to render outputs, including hook config, are kept and reported rather than silently reverted. Doctor and update are the control.
- A quarantined render output is not re-pinned. It is latent: nothing in the shipped lock can reach it.
- Symlink write-through on the non-render restore path, and dangling directory components, stay open until PR #184 merges.
- The template engine copy is not gate-protected (deferred to v0.2.1).
- The P0 type-swap gate bypass (#71 lineage) is still open in v0.2.0.
- This approval is signed with an agent-held verifier key. Custody hardening is the first v0.2.1 item.
