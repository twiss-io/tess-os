# Implement a paginated response envelope

`contract.json` in this directory is the machine-readable API contract for
`paginate_response()`. `pagination_contract.py` contains the function
stub. Implement it exactly to `contract.json`'s `rules` and `examples`.

Read `contract.json` before writing any code — it is the authoritative
spec. Do not guess at behavior it doesn't specify; where it's ambiguous,
the worked `examples` in that file are the tie-breaker.

Constraints:
- Do not modify `contract.json`.
- Do not change the function name or signature.
- No external dependencies — standard library only.
- Your implementation will be checked against the disclosed examples in
  `contract.json` PLUS additional cases you will not see before grading —
  implement the general rule, not a lookup table for the three examples
  shown.
